## Projects

### second-third-test

Map project "portolan test - second/third creek". It is a GeoLibre project file (JSON) that loads these layers directly from the published catalog on S3:

| Layer | Type | Source collection |
|-------|------|-------------------|
| Transit — data | COG | `risk-drivers/transit` |
| Structures — data | COG | `risk-drivers/structures` |
| 100yr — data | COG | `hazard-depth/100yr` |
| Rp 100yr — 100yr_FP | PMTiles | `hazard-floodplains/rp-100yr` |
| Structures — structure_risk | GeoParquet | `risk-scores-presentation/structures` |

The layers use absolute `https://portolan-test.s3.us-east-1.amazonaws.com/...` URLs, so the project works from any location and needs the published catalog to be reachable.

## Quick Start

Open `second-third-test.geolibre` in GeoLibre. To read it programmatically:

```python
import json
import urllib.request

url = "https://portolan-test.s3.us-east-1.amazonaws.com/maps/second-third-test.geolibre"
project = json.load(urllib.request.urlopen(url))
print(project["name"], [layer["name"] for layer in project["layers"]])
```
